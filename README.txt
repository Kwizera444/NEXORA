HOW TO RUN
----------

1. Install XAMPP.

2. Start Apache from XAMPP Control Panel.

3. Place the nexora_school folder inside:

   C:\xampp\htdocs\


4. Open your browser.

5. Visit:

   http://localhost/nexora_school/


PHP SERVER DATE/TIME
--------------------

Open:

http://localhost/nexora_school/datetime.php

HTTP STATUS CODE
----------------

When a page loads successfully through Apache,
the expected HTTP response status is:

200 OK


To inspect it:

1. Open the website.
2. Press F12.
3. Open Network.
4. Reload the page.
5. Click the HTML document.
6. Check Status Code.

Expected:

200
